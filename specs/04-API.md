# 04 — API Contracts (REST v1)

Base `/api/v1`; JSON; OpenAPI autogenerated from FastAPI. Pagination defaults limit=20, max=100. Public APIs return only `published` content. Stable error envelope: `{"error":{"code":"VALIDATION_ERROR","message":"...","details":{},"request_id":"..."}}`.

## Public
| Method | Route | Query/body | Response |
|---|---|---|---|
| GET | `/contents` | `type,topic,source,from,to,cursor,limit` | `{items,next_cursor}` |
| GET | `/contents/{id_or_slug}` | - | canonical content + provenance + taxonomy |
| GET | `/papers` | `q,task,from,to,has_code,cursor` | paginated papers |
| GET | `/repositories` | `q,task,license,sort,cursor` | paginated repositories |
| GET | `/news` | `q,topic,source,cursor` | paginated news |
| GET | `/taxonomy/dimensions` | - | dimensions |
| GET | `/taxonomy/nodes` | `dimension,parent_id` | tree nodes |
| GET | `/search` | `q,type,task,sort,cursor` | mixed results + facets |
| GET | `/contents/{id}/related` | `limit` | related resources |
| GET | `/health/live` | - | liveness |
| GET | `/health/ready` | - | readiness |

## Authenticated
| Method | Route | Request | Response |
|---|---|---|---|
| GET | `/me` | bearer | profile |
| POST | `/submissions` | `{type,url,title?,description?,taxonomy_node_ids?}` | 201 pending submission |
| GET | `/me/submissions` | bearer | paginated submissions |
| GET | `/submissions/{id}` | owner or moderator | submission detail |

## Moderator/Admin
| Method | Route | Request | Response |
|---|---|---|---|
| GET | `/admin/submissions` | `status,cursor` | review queue |
| POST | `/admin/submissions/{id}/approve` | `{notes?,taxonomy_node_ids?}` | approved and published result |
| POST | `/admin/submissions/{id}/reject` | `{reason}` | rejected result |
| GET | `/admin/ingestion/runs` | `source,status,cursor` | run statuses |
| POST | `/admin/ingestion/sources/{id}/run` | `{dry_run?:boolean}` | 202 accepted job id |
| GET | `/admin/audit` | filters | audit events |

## Validation and behavior
- Search `q` trimmed, 2–200 characters; escape/parameterize safely.
- Reject invalid taxonomy IDs; never silently invent tags.
- Submission URL: HTTP(S) only; DNS/IP validation against SSRF; block private/loopback/link-local/reserved addresses, redirects revalidated, bounded response sizes and timeouts.
- `POST` mutation endpoints use idempotency key when retryable.
- 401 unauthenticated; 403 forbidden; 404 nonexistent or intentionally concealed; 409 conflict/duplicate; 422 validation; 429 rate-limited.
- Public API cache policy must invalidate on moderation/unpublish.
